### 1. Depot System ✅ COMPLETO

**Arquivos Criados:**
- `internal/game/depot.go` (193 linhas)
- `internal/db/depot.go` (147 linhas)

**Funcionalidades:**
```go
// Depot estruturado hierarquicamente
type DepotLocker struct {
    Item    *Item
    DepotID uint16 // town ID
}

type PlayerDepotManager struct {
    player  *Player
    lockers map[uint16]*DepotLocker // um por cidade
}

// Features implementadas:
- Per-town depot (cada cidade tem seu próprio depot)
- Depot chests (17 boxes por locker, IDs 2590-2606)
- Item limit (2000 items por depot)
- Lazy initialization (chests criados sob demanda)
- Load/Save completo no DB (player_depotitems)
- Integrado com sistema de containers existente
```

**Integração:**
- Load: `LoadPlayerDepot()` chamado em `LoadPlayer()`
- Save: `SavePlayerDepot()` chamado em `SavePlayer()`
- Player API: `player.OpenDepot()`, `player.GetDepotItemCount()`
